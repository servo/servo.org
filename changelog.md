# Changelog

## Highlights

- the popover attribute, light dismiss for popovers and dialogs, closing with Esc, and modal dialogs now block the rest of the page ([@skyz1](https://github.com/skyz1), [@TimvdLippe](https://github.com/TimvdLippe), [@lukewarlow](https://github.com/lukewarlow), [#49432](https://github.com/servo/servo/pull/49432), [#49611](https://github.com/servo/servo/pull/49611), [#49640](https://github.com/servo/servo/pull/49640), [#49975](https://github.com/servo/servo/pull/49975), [#50044](https://github.com/servo/servo/pull/50044))
- :user-valid, :user-invalid, :required, :optional, :in-range, :out-of-range and :default pseudo-classes ([@skyz1](https://github.com/skyz1), [@lumiscosity](https://github.com/lumiscosity), [#49512](https://github.com/servo/servo/pull/49512), [#49509](https://github.com/servo/servo/pull/49509), [#49505](https://github.com/servo/servo/pull/49505), [#49767](https://github.com/servo/servo/pull/49767))
- align-content on block containers and table cells ([@Loirooriol](https://github.com/Loirooriol), [#49749](https://github.com/servo/servo/pull/49749), [#49862](https://github.com/servo/servo/pull/49862))
- Google Docs now loads, thanks to a basic PerformanceResourceTiming.workerStart ([@mrobinson](https://github.com/mrobinson), [#49566](https://github.com/servo/servo/pull/49566))
- the default focus ring now uses :focus-visible, so it only shows when appropriate (like keyboard navigation) ([@TimvdLippe](https://github.com/TimvdLippe), [#49423](https://github.com/servo/servo/pull/49423))
- text-underline-offset ([@shubhamg13](https://github.com/shubhamg13), [#49158](https://github.com/servo/servo/pull/49158))
- :focus-within pseudo-class ([@TimvdLippe](https://github.com/TimvdLippe), [@mrobinson](https://github.com/mrobinson), [#49440](https://github.com/servo/servo/pull/49440))
- showPicker() on <input> elements ([@TimvdLippe](https://github.com/TimvdLippe), [@lukewarlow](https://github.com/lukewarlow), [#50032](https://github.com/servo/servo/pull/50032))

## Embedding API

- Android: ServoView replaced with AndroidExternalSurface, back handling and soft keyboard moved into the library, and API cleanups ([@veyndan](https://github.com/veyndan), [#49268](https://github.com/servo/servo/pull/49268), [#49292](https://github.com/servo/servo/pull/49292), [#49472](https://github.com/servo/servo/pull/49472), [#49476](https://github.com/servo/servo/pull/49476), [#49494](https://github.com/servo/servo/pull/49494), [#50079](https://github.com/servo/servo/pull/50079), [#50087](https://github.com/servo/servo/pull/50087))
- WebDriver: more reliable waiting for navigations to finish ([@yezhizhen](https://github.com/yezhizhen), [#49817](https://github.com/servo/servo/pull/49817), [#49977](https://github.com/servo/servo/pull/49977), [#50006](https://github.com/servo/servo/pull/50006), [#50039](https://github.com/servo/servo/pull/50039))
- crypto.getRandomValues() and randomUUID() are always available, and SubtleCrypto is now behind the subtlecrypto feature (replacing webcrypto) ([@jschwe](https://github.com/jschwe), [@kkoyung](https://github.com/kkoyung), [#48860](https://github.com/servo/servo/pull/48860))
- embedders can now send IME text directly with ImeEvent::Commit, fixing composition events on OpenHarmony ([@jschwe](https://github.com/jschwe), [#49400](https://github.com/servo/servo/pull/49400))
- favicons now fall back to /favicon.ico and update properly when navigating ([@sabbCodes](https://github.com/sabbCodes), [@mrobinson](https://github.com/mrobinson), [#49513](https://github.com/servo/servo/pull/49513))
- temporary storage is now cleaned up properly when a config directory is set ([@xbwwj](https://github.com/xbwwj), [#49712](https://github.com/servo/servo/pull/49712))
- embedders can now save the HTTP cache to disk, and servoshell does so on exit ([@Narfinger](https://github.com/Narfinger), [@jdm](https://github.com/jdm), [#49033](https://github.com/servo/servo/pull/49033))
- the positions of embedder-drawn controls (like <select> pickers) are now correct with pinch zoom, scrolling and iframes ([@mrobinson](https://github.com/mrobinson), [#49750](https://github.com/servo/servo/pull/49750))
- embedders can now disable the aws-lc-rs feature and choose their own TLS crypto provider ([@ZettaScript](https://github.com/ZettaScript), [#49693](https://github.com/servo/servo/pull/49693))
