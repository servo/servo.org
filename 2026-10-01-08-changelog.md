# Changelog

## Highlights

- `<input type=image>` is now supported, only missing `width` and `height` IDL attributes ([@SilvioPilato](https://github.com/SilvioPilato), [#48265](https://github.com/servo/servo/pull/48265))
- `<input type=range>` is now interactive, keyboard support missing yet ([@webbeef](https://github.com/webbeef), [#48342](https://github.com/servo/servo/pull/48342))

## Embedding API

- Breaking change: `RequestInterceptor` now gets `ServoUrl` instead of `Url`, this is an optimization to avoid a conversion/allocation ([@Narfinger](https://github.com/Narfinger), [#48588](https://github.com/servo/servo/pull/48588))

## Web platform (DOM)

- WebGL 2 conformance fixes ([@mxmgorin](https://github.com/mxmgorin), [#48560](https://github.com/servo/servo/pull/48560), [#48571](https://github.com/servo/servo/pull/48571), [#48651](https://github.com/servo/servo/pull/48651), [#48620](https://github.com/servo/servo/pull/48620), [#48678](https://github.com/servo/servo/pull/48678), [#48689](https://github.com/servo/servo/pull/48689), [#48751](https://github.com/servo/servo/pull/48751))
- Support dimension attributes for `<marquee>`, `<img>` margins ([@TimvdLippe](https://github.com/TimvdLippe), [#48604](https://github.com/servo/servo/pull/48604), [#48605](https://github.com/servo/servo/pull/48605))
- Touch support: compatibility fixes for mouse events ([@yezhizhen](https://github.com/yezhizhen), [#48671](https://github.com/servo/servo/pull/48671), [#48699](https://github.com/servo/servo/pull/48699))
- Web Audio `DelayNode` now supported, no cycle handling ([@kevlu93](https://github.com/kevlu93), [#47957](https://github.com/servo/servo/pull/47957))
- `beforeinput` now works in text fields and partially in `contenteditable` ([@dzfrias](https://github.com/dzfrias), [#48519](https://github.com/servo/servo/pull/48519))
- IndexedDB `IDBCursor` `update()` and `delete()` are now implemented, experimental feature `--pref dom_indexeddb_enabled` ([@kuntal-devrat](https://github.com/kuntal-devrat), [#48402](https://github.com/servo/servo/pull/48402))
- Support `navigator.serviceWorker.onmessage/onmessageerror` handlers, experimental feature `--pref dom_serviceworker_enabled` ([@gterzian](https://github.com/gterzian), [#48680](https://github.com/servo/servo/pull/48680))
- IME composition fixes ([@dzfrias](https://github.com/dzfrias), [#48690](https://github.com/servo/servo/pull/48690))

## Web platform (layout)

- Fix aspect ratio for SVG `viewBox` with fractional values ([@leowatts](https://github.com/leowatts), [#48556](https://github.com/servo/servo/pull/48556))
- Line layout fixes related to soft wrap line breaks ([@mrobinson](https://github.com/mrobinson), [@Loirooriol](https://github.com/Loirooriol), [#48564](https://github.com/servo/servo/pull/48564))
- Flex items layout only once when cross size is known ([@webbeef](https://github.com/webbeef), [#48485](https://github.com/servo/servo/pull/48485))
- Enable CSS `progress()` function by default ([@Loirooriol](https://github.com/Loirooriol), [#48474](https://github.com/servo/servo/pull/48474))
- Stylo upgrade Oct 1st, which brings support for `background-blend-mode: plus-lighter` ([@Loirooriol](https://github.com/Loirooriol), [#48528](https://github.com/servo/servo/pull/48528))
- Grid layout interop improvements ([@RichardTjokroutomo](https://github.com/RichardTjokroutomo), [#48644](https://github.com/servo/servo/pull/48644))
- Line layout fixes related to hanging and removed whitespaces ([@mrobinson](https://github.com/mrobinson), [#48591](https://github.com/servo/servo/pull/48591))
