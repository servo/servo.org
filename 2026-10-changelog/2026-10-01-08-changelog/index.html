Changelog

Highlights

  • <input type=image> is now supported, only missing width and height IDL attributes (@SilvioPilato, #48265)
  • <input type=range> is now interactive, keyboard support missing yet (@webbeef, #48342)

Embedding API

  • Breaking change: RequestInterceptor now gets ServoUrl instead of Url, this is an optimization to avoid a conversion/allocation (@Narfinger, #48588)

Web platform (DOM)

  • WebGL 2 conformance fixes (@mxmgorin, #48560, #48571, #48651, #48620, #48678, #48689, #48751)
  • Support dimension attributes for <marquee>, <img> margins (@TimvdLippe, #48604, #48605)
  • Touch support: compatibility fixes for mouse events (@yezhizhen, #48671, #48699)
  • Web Audio DelayNode now supported, no cycle handling (@kevlu93, #47957)
  • beforeinput now works in text fields and partially in contenteditable (@dzfrias, #48519)
  • IndexedDB IDBCursor update() and delete() are now implemented, experimental feature --pref dom_indexeddb_enabled (@kuntal-devrat, #48402)
  • Support navigator.serviceWorker.onmessage/onmessageerror handlers, experimental feature --pref dom_serviceworker_enabled (@gterzian, #48680)
  • IME composition fixes (@dzfrias, #48690)

Web platform (layout)

  • Fix aspect ratio for SVG viewBox with fractional values (@leowatts, #48556)
  • Line layout fixes related to soft wrap line breaks (@mrobinson, @Loirooriol, #48564)
  • Flex items layout only once when cross size is known (@webbeef, #48485)
  • Enable CSS progress() function by default (@Loirooriol, #48474)
  • Stylo upgrade Oct 1st, which brings support for background-blend-mode: plus-lighter (@Loirooriol, #48528)
  • Grid layout interop improvements (@RichardTjokroutomo, #48644)
  • Line layout fixes related to hanging and removed whitespaces (@mrobinson, #48591)

Performance

  • Multiple perf improvements, reducing allocations and more things (@yezhizhen, @Narfinger, #48549, #48558, #48598, #48615, #48565, #48569, #48677, #48562, #48650, #48675, #48589, #47720, #48745, #48703, #48750)
  • Several fixes to avoid unneeded avoid (@Taym95, #48568, #48646, #48654, #48702, #48720, #48721)
  • Optimization when converting typed arrays in WebIDL (@jdm, #48640)
  • Fixed memory leak where pending setTimeout() timers kept closed windows and iframes alive (@jschwe, #48752)

DevTools

  • Console: fixed object <prototype> (@sahilnyk, #48208)

servoshell

  • Android: ongoing migration to Jetpack Compose (@veyndan, #48544, #48518, #48574, #48573, #48595, #48596, #48601, #48592, #48608, #48607, #48609, #48594)
  • New command line flag --memory-output that turns on memory reports for benchmarking (@Narfinger, #48393)

Work in progress

  • New SVG crate: data model for native SVG rendering (@mu-mostafa98, @jdm, #48467)
  • WebGPU performance and correctness improvements (@sagudev, @jdm, #48372)
