Changelog

Highlights

  • the popover attribute, light dismiss for popovers and dialogs, closing with Esc, and modal dialogs now block the rest of the page (@skyz1, @TimvdLippe, @lukewarlow, #49432, #49611, #49640, #49975, #50044)
  • :user-valid, :user-invalid, :required, :optional, :in-range, :out-of-range and :default pseudo-classes (@skyz1, @lumiscosity, #49512, #49509, #49505, #49767)
  • align-content on block containers and table cells (@Loirooriol, #49749, #49862)
  • Google Docs now loads, thanks to a basic PerformanceResourceTiming.workerStart (@mrobinson, #49566)
  • the default focus ring now uses :focus-visible, so it only shows when appropriate (like keyboard navigation) (@TimvdLippe, #49423)
  • text-underline-offset (@shubhamg13, #49158)
  • :focus-within pseudo-class (@TimvdLippe, @mrobinson, #49440)
  • showPicker() on elements (@TimvdLippe, @lukewarlow, #50032)

Embedding API

  • Android: ServoView replaced with AndroidExternalSurface, back handling and soft keyboard moved into the library, and API cleanups (@veyndan, #49268, #49292, #49472, #49476, #49494, #50079, #50087)
  • WebDriver: more reliable waiting for navigations to finish (@yezhizhen, #49817, #49977, #50006, #50039)
  • crypto.getRandomValues() and randomUUID() are always available, and SubtleCrypto is now behind the subtlecrypto feature (replacing webcrypto) (@jschwe, @kkoyung, #48860)
  • embedders can now send IME text directly with ImeEvent::Commit, fixing composition events on OpenHarmony (@jschwe, #49400)
  • favicons now fall back to /favicon.ico and update properly when navigating (@sabbCodes, @mrobinson, #49513)
  • temporary storage is now cleaned up properly when a config directory is set (@xbwwj, #49712)
  • embedders can now save the HTTP cache to disk, and servoshell does so on exit (@Narfinger, @jdm, #49033)
  • the positions of embedder-drawn controls (like and the File and Directory Entries API (behind dom_entries_api_enabled) (@yezhizhen, #49417, #49660, #49738, #49752, #49887, #49935, #49952, #50070, #50084)
  • many WebGL and WebGL 2 fixes, including zero-initialised texture storage and non-power-of-two mipmaps (@mxmgorin, @SharanRP, @rishiiicreates, #49404, #49436, #49632, #49902, #49912, #50012, #50034, #50067)
  • [WIP] rich text editing (contenteditable and execCommand, behind dom_exec_command_enabled): the caret is now shown, the outdent command, and many line break fixes (@Psychpsyo, @TimvdLippe, #47459, #48253, #49797, #49818, #49884, #49917, #49920, #50062)
  • FontFaceSet.status, FontFaceSetLoadEvent and the loading, loadingdone and loadingerror events, and FontFace and FontFaceSet in workers (@Daniel-1600, @rogerkorantenng, #49905, #49955, #50037, #50046, #50049)
  • ResizeObserver is now complete: more accurate device pixel sizes, less layout work, and other fixes (@mrobinson, #49949, #49950, #49953, #50094, #50075)
  • URLs in preloads, stylesheets and media sources are now parsed using the document’s encoding (@sabbCodes, @programskillforverification, @morehwachege, #49199, #49471, #49111)
  • [WIP] progress on navigation: stopped loads are handled properly (with a new load status for embedders), and the latest
